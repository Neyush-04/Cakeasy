# Cakeasy Marketing Quick Start

One page. For details see the [Operations Manual](OPERATIONS_MANUAL.md).

## 1. Sign in
Open **www.cakeasy.in/admin** → **Continue with Google**. Use the Gmail account
the owner added in **Users & roles**. There are no passwords to share. If you
see "No CMS access", ask the owner to add your email.

## 2. Answer enquiries first
**Enquiries** lists every brief sent from the website, newest first, each with a
reference like `CK-23030A`. The same reference is in the customer's WhatsApp
message. Open one → **Reply on WhatsApp** → then set the **Status**
(contacted → quoted → confirmed / lost) and add a **Follow up on** date.
The Dashboard shows follow-ups that are due.

## 3. Share tagged links, never the bare address
**Marketing & tracking › Campaign link builder**: pick the page, where you'll
share it (Instagram bio, WhatsApp status, printed card…), add a campaign name,
**Copy**. Optional: **Create short link** such as `cakeasy.in/insta`.
Enquiries from that link then show their source.

## 4. Keep each page's Google snippet sharp
**SEO** › pick a page. Edit the **SEO title** (under 60 characters) and **Meta
description** (120–160). Watch the Google preview on the right.
**Save draft** is private; **Publish** makes it live in about 2–3 minutes.

## 5. Set the WhatsApp/Instagram link preview
In the same SEO page: **Share image** → **Choose** a real cake photo. That is the
picture people see when the link is shared.

## 6. Moved or retired a link? Add a redirect
**Redirects** › **New redirect**: old address → new page. Use **Permanent** for
moves and **Temporary** for campaigns. Never leave printed QR codes pointing at
a dead page.

## 7. Keep business details identical everywhere
**Studio settings**: WhatsApp number, phone, email, address, social links and
the Google Business Profile link. They must match the Google Business Profile
exactly.

## 8. Tracking IDs live in the CMS, not in code
**Marketing & tracking**: paste the GA4 Measurement ID (`G-…`), the Meta Pixel ID,
and the Google, Bing and Meta verification codes. A cookie banner appears
automatically once an ID is set.

## 9. Never do these
- Paste scripts, pixels or tracking codes anywhere except the ID fields.
- Invent reviews, ratings, customer counts, prices, delivery or eggless claims.
- Share `/admin` links or customer details publicly, or put phone numbers in links.
- Point a redirect at another redirect.

## 10. Before any campaign goes live
- [ ] Landing page checked on a phone.
- [ ] SEO title, description and share image published.
- [ ] Tagged link (or short link) created and opened once.
- [ ] One test enquiry from that link shows the right source in **Enquiries**
      (then mark it **spam** or delete it).
- [ ] Neha knows the campaign is running and can handle the WhatsApp volume.
